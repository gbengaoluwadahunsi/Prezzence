## How to Further Reduce Size (Optional)

### Option 1: Remove Local Model ZIPs (-349 MB)
```powershell
Remove-Item backend/static/duix-models/*.zip
```
Models will be served from GitHub/Supabase instead.

### Option 2: Remove React Native Reference (-1 MB)
```powershell
Remove-Item -Recurse _rn_source
```
Only needed for comparing implementations.

### Option 3: Remove Marketing Assets (-1 MB)
```powershell
Remove-Item -Recurse marketing
```
Only needed for promotional materials.
